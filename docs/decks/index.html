1. Reading guide

Use each output for its stated purpose

Core rule. A candidate-gene list is a prioritization output. It does not establish causality, allele phase, pathway activity, or clinical relevance.

Candidate seed gene

A gene with at least one variant that passes Phase 0 research gates. This label selects genes for downstream analysis.

Network edge

A STRING association above the selected confidence threshold. An edge does not show causal direction or a direct physical interaction.

Enriched term

An annotation term that is over-represented against a specific background. It does not demonstrate pathway activity.

Adjusted value

An FDR or Benjamini-Hochberg value from one provider. Do not pool adjusted values across providers.

Interpretation boundary. This report discusses aggregate research outputs. It does not expose genomic coordinates, alleles, genotypes, sample identifiers, or phenotype narratives.

4. VCF-derived gene analysis

Phase 0 selects variants. Phase 1 creates candidate seed genes.

AnnotateUse consequence, population, clinical, splice, and missense evidence.
Check coordinatesRequire a chromosome, positive position, reference allele, and alternate allele.
Apply research gatesTest rarity and at least one impact criterion.
Aggregate by geneGenes with one or more passing variants become network seeds.

Rarity rule in code

Pass when the consolidated allele frequency is ≤ 0.001, or when gnomAD reports the allele as not found.

Unknown frequency has a narrow exception for genes in an MVA biological category.

Impact rule in code

Pass with a high-impact consequence, P/LP ClinVar label, CADD ≥ 20, SpliceAI ≥ 0.2, REVEL ≥ 0.5, or AlphaMissense ≥ 0.5.

Implementation difference. Narrative reports describe NHOMALT < 5 as a rarity gate. Current code records population homozygotes but does not apply that threshold as a gate.

10. Integrated interpretation

Evidence converges on a research hypothesis, not an established mechanism

What aligns

  • Published papers support chromosome-stability roles for known MVA-related genes.
  • Candidate filtering provides a reproducible seed list for exploration.
  • STRING reports a focused component containing established checkpoint genes.
  • Phase 2 contains statistically significant broad annotation terms.

What does not align

  • Independent custom-background enrichment has no BH-significant term.
  • DAVID maps fewer identifiers and uses a different statistical system.
  • Broad terms do not isolate a unique spindle-checkpoint mechanism.
  • Gene selection can bias enrichment through coverage and annotation density.
Working conclusion. The combined outputs identify candidate genes and a follow-up network context that are compatible with chromosome-segregation biology. They do not demonstrate that any selected variant causes a disorder or activates a pathway.

11. Validation, next steps, and sources

Resolve discrepancies before stronger interpretation

Required validation

  1. Reconcile filtering code, saved tables, and narrative reports.
  2. Use an approved orthogonal method to check candidate variants.
  3. Resolve allele phase with family data or long-read evidence when available.
  4. Test proposed cellular mechanisms with suitable functional assays.
  5. Rerun enrichment with a documented callable-gene universe.

Limits that remain

  • In-silico predictions do not measure functional effect.
  • Short-read multi-hit patterns do not prove a biallelic configuration.
  • Network topology does not show direction or treatment relevance.
  • Annotation enrichment does not show pathway activity.
